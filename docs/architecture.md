# Architecture

The package is divided along algorithmic trust boundaries.

- `domain.py` and `routes.py` define and verify the routing problem.
- `master.py` is the trusted linear/integer optimization layer.
- `pricing.py` is the trusted exact pricing implementation.
- `features.py` and `learning.py` are heuristic guidance components.
- `column_generation.py` controls when heuristic output is accepted and when exact fallback is mandatory.
- `dataset.py`, `benchmark.py`, and `experiment.py` implement reproducible research workflows.

The learned model never alters route feasibility rules, customer coverage equations, dual values, or reduced-cost arithmetic. It returns only arc scores. Every selected route is generated by the same resource-feasible label-setting code used for exact pricing, but on a restricted graph.
